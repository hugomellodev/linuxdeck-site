Posso usar um celular antigo?+

Sim. O LinuxDeck foi pensado para Android 6.0 ou superior, com o Android System WebView atualizado. O desempenho pode variar conforme o aparelho.

Preciso estar na mesma rede Wi-Fi?+

Sim. O celular precisa alcançar o computador pela rede local. O PC pode estar conectado por cabo ao mesmo roteador. Algumas redes de convidados bloqueiam essa comunicação.

Vou precisar de um código toda vez?+

Não. Você autoriza o celular no computador no primeiro acesso. Depois, o app lembra da conexão. Apagar os dados ou reinstalar o app pode exigir uma nova autorização.

O computador precisa ficar ligado?+

Sim. O computador precisa estar ligado e com o servidor LinuxDeck ativo para receber os comandos.
